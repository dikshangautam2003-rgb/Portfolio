# Dikshan Gautam — V7 Editorial Personal Website

This version is a from-scratch visual/content architecture redesign based on current portfolio/editorial research.

## Design direction
- Editorial personal brand rather than SaaS/freelancer dashboard.
- Moderate typography: large enough for hierarchy, deliberately smaller than previous V6.
- Warm paper background, ink, muted secondary tone and one oxblood accent.
- DM Sans for UI/body + Instrument Serif for selected display moments.
- Photography is used as art direction, not as decorative card filler.
- Asymmetric grids, rules, editorial rows and restrained cards replace generic rounded-card layouts.
- Motion is limited to subtle reveal and hover behavior and respects `prefers-reduced-motion`.

## Homepage structure
1. Hero with stock editorial visual and positioning
2. Selected work / real evidence
3. Search Console evidence
4. Services: Search, Content, Web with image-led blocks
5. Point of view
6. Education library
7. Writing / blog
8. About
9. Contact CTA

## SEO
- Descriptive page titles and meta descriptions.
- Canonical URLs.
- Robots + XML sitemap.
- Semantic H1/H2 hierarchy.
- Internal links between services, education and articles.
- Homepage Person structured data.
- No fabricated rankings, traffic attribution, client logos or testimonials.

## Evidence
The supplied Google Search Console screenshot is used as evidence exactly as supplied. The site explicitly avoids claiming that all displayed performance is attributable to Dikshan personally unless the underlying context is established.

## Visual sources / research direction
The design takes principles from contemporary editorial portfolios and personal sites such as Abul Khoyer, Tarik Karahodzic, Angelo Roic, A1 editorial references, and selected independent consultant sites. It borrows principles rather than copying code/assets.

Stock imagery currently uses Unsplash-hosted photographs as temporary art direction. Replace those with original photography or licensed brand imagery before final production if preferred.

## Validation
All primary routes were served locally and returned HTTP 200 during the redesign pass, including Education categories, Scholarships, Blog articles, Services, About, Contact, sitemap and robots.txt.
