Photography

The v4 site uses real photography from Unsplash via image URLs. The images are not AI-generated. Image source/usage information is documented in the project change notes supplied with this release.

Deployment

The website root must contain index.html, assets/, about/, services/, work/, contact/, insights/, CNAME, robots.txt and sitemap.xml.
Do not upload the enclosing dikshan-site folder as an extra directory inside the GitHub Pages root.
