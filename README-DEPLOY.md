# Dikshan v2 — deployment package

This is a complete static-site replacement for the Dikshan website.

## Main changes
- Navbar: Home, Education, Products, Travel, About, Contact, Search
- No Research in the main navbar
- Education / Products / Travel desktop mega-menus
- Expandable mobile navigation
- Brand palette limited to Dikshan blue #25479D and red #ED2D2A, with neutral UI colours
- Medium, restrained headings in brand blue
- Real image-led category and editorial sections
- No "coming soon", "your blog will be here", lorem ipsum or research-queue filler
- Existing favicon/CNAME/Bing verification/technical SEO files preserved
- Existing URL structure retained where useful
- Vercel permanent redirects retained for legacy portfolio URLs

## Deploy
Replace the files in your GitHub repository with this package, keeping the repository's `.git` directory if you are doing a local replacement, then commit and push.

## Important
Some real editorial images are referenced from Unsplash/Wikimedia/UNICEF source URLs to keep this package lightweight. See IMAGE-SOURCES.md for attribution/source information.

Before commercial launch, verify image licensing/attribution requirements for every image you keep.
