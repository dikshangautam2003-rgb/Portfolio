Design
------
Warm paper background + deep ink + indigo/blue + coral red.
Primary type uses Helvetica Neue with Helvetica/Arial fallbacks.
Serif italic is used only as a deliberate editorial accent.
No frameworks or build tools are required.

CONTACT FORM

dikshangautam2003@gmail.com

IMPORTANT:
Change the hidden _next URL in contact.html from:
https://YOUR-DOMAIN.com/contact.html?sent=1
to your actual deployed URL if you want a custom post-submit redirect.

Before publishing
-----------------
1. Replace YOUR-DOMAIN.com in the _next field and any metadata you later add.
2. Replace the monogram asset with your own professional portrait if you want a personal photo.
3. Add GitHub/Instagram/other links if needed.
4. Review every claim and replace representative work with real screenshots/case studies as you collect them.
5. Upload the whole folder, keeping the directory structure intact.

This is a static HTML/CSS/JS site. It can be hosted on Netlify, Vercel, GitHub Pages or similar static hosting.
