# Dikshan V7 — Visual & Copy Direction

## Position
Dikshan is a Nepal-focused decision-support publication: deep research underneath, simple and honest advice on the surface.

## Design system
- Ink: #14213D
- Navy: #102A66
- Blue: #1F56C9
- Red: #D83A35
- Paper: #F7F6F1
- White: #FFFFFF
- Warm neutral: #F0EDE5
- Muted text: #5D6675
- Divider: #D9DCE2
- Display: Georgia / editorial serif
- UI/body: Inter/system sans
- Container: 1240px max, 32px mobile gutters
- Corners: 0–4px, mostly square
- Shadows: reserved for floating/overlapping utility elements
- Motion: short, subtle translate/opacity; reduced-motion supported

## Content hierarchy
1. One clear H1 per page.
2. H2s name the job of the section, not a marketing slogan.
3. H3s name the actual option/category.
4. Eyebrows are short navigational labels, not primary content.
5. Link text describes the destination/action.
6. Put the most decision-relevant information early and keep sections scannable.

## Homepage structure
Header → clear decision-focused hero → three decision entry points → three editorial pillars → principles/trust → selected guides → contact → footer.

## Pillar structure
Pillar H1 → concise purpose statement → category entry points → selected guides → decision factors/checklist → supporting FAQs where useful → related guides.

## Card rule
Cards are used only when the user needs to compare discrete choices. Editorial lists, article indexes and principles use dividers and whitespace instead of turning every block into a card.

## Copy voice
Direct, calm, useful, specific. Avoid hype, fake certainty, “ultimate/best ever”, filler, invented statistics, and generic AI-style slogans. Prefer “compare”, “understand”, “check”, “choose”, “fits”.
